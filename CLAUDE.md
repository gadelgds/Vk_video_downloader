# Проект: Загрузчик видео из VK и YouTube - GUI Версия

Десктопное приложение для скачивания видео из ВКонтакте (`vk.com`, `vkvideo.ru`) и YouTube (`youtube.com`, `youtu.be`, Shorts), включая приватные видео и выбор качества.

## 1. Стек технологий
* **Язык программирования:** Python 3.10+
* **Ядро загрузчика:** Библиотека `yt-dlp[default]` + `yt-dlp-ejs`
* **JS Runtime для YouTube (n-challenge):** Node.js / Deno
* **Склейка аудио/видео:** `ffmpeg` / `ffprobe`
* **Графический интерфейс (GUI):** `customtkinter`

## 2. Возможности
1. **Поддержка платформ:**
   * **ВКонтакте:** публичные и приватные видео, клипы, стримы.
   * **YouTube:** стандартные видео, YouTube Shorts, мобильные ссылки `youtu.be`.
2. **Решение JavaScript challenge (n-sig):** интеграция с системным Node.js / Deno и пакетом `yt-dlp-ejs` для расшифровки всех форматов YouTube (включая 1080p, 4K, 60fps).
3. **Пакетная загрузка:** вставка нескольких ссылок (каждая с новой строки) и последовательное скачивание.
4. **Выбор качества:** получение доступных разрешений (1080p, 720p, 480p и т.д.) либо автоматический выбор лучшего качества.
5. **Авторизация через Cookies:** чтение сессии из установленных браузеров (Chrome, Edge, Firefox, Opera, Safari, Vivaldi) для скачивания приватных видео или обхода ограничений YouTube.
6. **Поддержка Прокси (HTTP / SOCKS5):** возможность указать локальный или внешний прокси (например, `socks5://127.0.0.1:10808` или `http://127.0.0.1:7890`) для обхода замедлений и блокировок YouTube в РФ.
7. **Надежная работа с SSL:** объединение системного хранилища сертификатов Windows и бандла `certifi`.

## 3. Запуск и обновление
* `start.bat` — запуск приложения через виртуальное окружение `venv`.
* `update.bat` — обновление зависимостей (`yt-dlp`, `yt-dlp-ejs`, `certifi`, `customtkinter`).
