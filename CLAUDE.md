# Проект: Загрузчик медиа (VK, YouTube, TheASMRIndex, QQASMR) - GUI Версия

Десктопное приложение для скачивания видео и аудио с популярных платформ: ВКонтакте (`vk.com`, `vkvideo.ru`), YouTube (`youtube.com`, `youtu.be`, Shorts), TheASMRIndex (`theasmrindex.com`) и QQASMR (`qqasmr.com`).

## 1. Стек технологий
* **Язык программирования:** Python 3.10+
* **Ядро загрузчика:** Библиотека `yt-dlp[default]` + `yt-dlp-ejs`
* **JS Runtime для YouTube (n-challenge):** Node.js / Deno
* **Склейка аудио/видео:** `ffmpeg` / `ffprobe`
* **Графический интерфейс (GUI):** `customtkinter`

## 2. Поддерживаемые платформы
1. **ВКонтакте:** публичные и приватные видео, клипы, стримы.
2. **YouTube:** стандартные видео, YouTube Shorts, мобильные ссылки `youtu.be`.
3. **TheASMRIndex:** автоматическое распознавание каталожных ссылок (`/video/...`, `/channel/...`, `/live/twitch/...`) и преобразование в целевые медиа-потоки без Cloudflare-блокировок.
4. **QQASMR:** авторизация через сессионные cookies браузера, извлечение прямых подписанных MP4-видеопотоков в высоком качестве (720p HD со звуком) и отдельных дорожек M4A.

## 3. Возможности интерфейса
* **Современный карточный дизайн (Card Layout)** с закругленными блоками и переключателем темы оформления (Тёмная / Светлая / Системная).
* **Интерактивные бейджи и подсчёт ссылок:** автоматическое определение платформы каждой ссылки и вывод статистики.
* **Быстрые действия:** кнопки «Вставить из буфера» и «Очистить».
* **Детальная статистика в реальном времени:** отображение скорости скачивания (МБ/с), скачанного объёма и общего размера, а также оставшегося времени (ETA).
* **Управление очередью:** возможность отмены текущей загрузки и остановки очереди по кнопке «ОТМЕНА».
* **Прямой переход:** кнопка «📂 Открыть папку» для быстрого перехода к скачанным файлам в Проводнике Windows.
* **Автосохранение настроек:** папка, прокси, выбранный браузер и тема сохраняются в `config.json`.

## 4. Запуск и обновление
* `start.bat` — запуск приложения через виртуальное окружение `venv`.
* `update.bat` — обновление зависимостей (`yt-dlp`, `yt-dlp-ejs`, `certifi`, `customtkinter`).
