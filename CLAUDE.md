# Проект: Загрузчик видео из VK (vkvideo.ru) - GUI Версия

В этом файле описана архитектура, стек технологий и план разработки десктопного приложения для скачивания видео с `vkvideo.ru`.

## 1. Концепция и Требования
Пользователю необходимо приложение с графическим интерфейсом (GUI) для удобного скачивания видеороликов из ВКонтакте, включая **приватные видео** (из закрытых групп, личных сообщений и т.д.).

**Почему сторонние сервисы не справляются?**
* Переезд VK на новый видео-домен `vkvideo.ru`.
* Использование стриминга HLS/m3u8 (видео разбито на фрагменты).
* Приватные видео требуют авторизации (cookies).

**Наше решение:**
Десктопное приложение, которое использует под капотом мощный движок `yt-dlp`. `yt-dlp` умеет склеивать HLS-стримы и читать cookies из установленного браузера пользователя (Chrome, Firefox, Edge и т.д.), что решает проблему доступа к закрытым видео.

## 2. Стек технологий
Так как нам нужен GUI и интеграция с утилитой (или Python-библиотекой) `yt-dlp`, идеальным выбором будет язык Python.

*   **Язык программирования:** Python 3.10+
*   **Ядро загрузчика:** Библиотека `yt-dlp` (устанавливается через pip). Использование её как библиотеки позволит легко получать прогресс загрузки и выводить его в интерфейс.
*   **Графический интерфейс (GUI):** `customtkinter`. Это современная надстройка над стандартным Tkinter, которая позволяет делать красивые, темные/светлые современные интерфейсы в стиле Windows 11/MacOS, не усложняя при этом код (как это делает PyQt).
*   **Сборка:** `PyInstaller` или `auto-py-to-exe` — для компиляции Python-скрипта в один исполняемый файл `.exe`, чтобы программу можно было запускать без установки Python.

## 3. Архитектура интерфейса (Набросок)
Окно программы будет содержать:
1.  **Поле ввода:** Сюда вставляется ссылка на видео (например, `https://vkvideo.ru/video-12345_67890`).
2.  **Выпадающий список (или галочка) "Браузер для Cookies":** Позволит пользователю выбрать, из какого браузера взять авторизацию (Chrome, Edge, Firefox, Yandex), чтобы скачать закрытое видео.
3.  **Кнопка "Выбрать папку":** Куда сохранять скачанный файл.
4.  **Кнопка "СКАЧАТЬ":** Запускает процесс.
5.  **Прогресс-бар:** Показывает процент скачивания.
6.  **Текстовое поле логов (статус):** Показывает, что происходит (поиск видео, скачивание фрагментов, сборка, готово).

## 4. План разработки
1.  **Настройка окружения:** Инициализация виртуального окружения Python, установка `yt-dlp` и `customtkinter`.
2.  **Разработка ядра (Logic):** Написание класса-обертки для `yt-dlp`, настройка передачи cookies и перехвата прогресса скачивания (hook).
3.  **Разработка GUI (Интерфейс):** Создание окна, кнопок, полей ввода.
4.  **Связывание GUI и Ядра:** Запуск процесса скачивания в отдельном потоке (Thread), чтобы интерфейс не зависал во время скачивания.
5.  **Тестирование:** Проверка скачивания публичного и приватного видео.
6.  **Сборка:** Компиляция в `.exe` файл.
